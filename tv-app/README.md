# CKast TV App

Open this folder in VS Code when using the Samsung Tizen TV extension.

## Build And Install

1. Update the PC server IP in `js/main.js`.
2. Run `Tizen TV: Set Target Device Address`.
3. Run `Tizen TV: Build Signed Package`.
4. Run `Tizen TV: Launch Application` and choose `Run On TV`.

The PC broadcaster is outside this folder at `../pc-broadcaster/` and must be started separately.
